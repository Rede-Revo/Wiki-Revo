# 🪵 Terrenos

## Tempo offline necessário para perda da proteção.

Tempo para expirar o terreno por tempo offline de acordo com o tamanho do terreno.

<table><thead><tr><th width="367">Quantidade de blocos</th><th>Tempo Offline</th><th width="236">Preço máximo para reivindicar</th></tr></thead><tbody><tr><td>De 0 até 999 blocos de proteção</td><td>90 dias</td><td>249.750,00 Coins</td></tr><tr><td>De 1.000 até 9.999 blocos de proteção</td><td>120 dias</td><td>2.499.750,00 Coins</td></tr><tr><td>De 10.000 até 24.999 blocos de proteção</td><td>150 dias</td><td>6.249.750,00 Coins</td></tr><tr><td>De 25.000 até 100.000 blocos de proteção</td><td>240 dias</td><td>25.000.000,00 Coins</td></tr><tr><td>Mais de 100.001 blocos de proteção</td><td>360 dias</td><td>-</td></tr></tbody></table>

{% hint style="warning" %}
## ATENÇÃO

Atualmente é necessário acessar o mesmo mundo que o terreno está para resetar a contagem de dias offline.&#x20;
{% endhint %}

{% hint style="info" %}
O preço máximo para reivindicação é considerando o pior cenário, o valor pode alterar em relação ao tamanho e quantidade de dias que o jogador está offline.

Para proteções com mais de 100.001 blocos de proteção não é possível determinar o valor máximo, já que os terrenos no survival podem ter qualquer tamanho.\*
{% endhint %}

{% hint style="info" %}
Para adquirir terrenos expirados use o comando /terreno reivindicar.

Cada bloco de proteção para reivindicação custa 250 Coins, mas reduz 1 coin por dia excedente, podendo ficar no preço mínimo por bloco de 25 Coins.
{% endhint %}

{% hint style="info" %}
Os terrenos de jogadores banidos seguem o mesmo prazo.
{% endhint %}

<sup><sub>\*Atualmente foi adicionado um limite máximo de 250.000 blocos por terrenos, não sendo possível expandir mais que isso.<sub></sup>
