# 🪙 Comandos

* Para ver seus Cashs, digite /cash
* Para ver o histórico de transações, basta digitar /cash log.&#x20;
* Para ver o jogador mais rico do momento em nosso servidor, basta digitar /cash top.
* Para enviar Cash para outro jogador use /cash pay \<nick> \<valor>.
