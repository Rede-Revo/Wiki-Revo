# Passe de Batalha

## Introdução

Cada Passe oferece tags referente a temporada em andamento, o jogador pode cumprir as missões e resgatar as tags\* até o fim da temporada, após o encerramento, não é mais possível resgatar as tags.

Ao resgatar uma tag do Passe de Batalha, a tag é ativada no mesmo momento na conta do jogador, não sendo possível obter o item ativável da tag, após o resgate da tag, ela permanecerá na conta conta permanentemente.&#x20;

{% hint style="info" %}
Algumas tags precisam do Passe de Batalha premium, que pode ser adquirido no /cash shop.

Mesmo adquirindo o Passe premium ainda é necessário realizar as missões para subir de categoria.&#x20;
{% endhint %}

{% hint style="info" %}
Mais informações sobre o [Passe de Batalha clique aqui](../../passe-de-batalha.md).
{% endhint %}

{% hint style="info" %}
A visualização da tag pode ser consultada diretamente pelo /tags, em breve estará disponível a visualização por aqui.
{% endhint %}
