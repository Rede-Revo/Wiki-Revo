# Pacotes

## Introdução

A categoria Pacotes reúne tags temáticas do Survival disponíveis pelo `/cash shop`, sendo possível comprar uma tag separadamente ou adquirir todas as tags de um pacote com 20% de desconto em relação ao valor total.

O valor do pacote completo corresponde ao conjunto de tags indicado em cada tabela.

## Como obter

Acesse o `/cash shop`, entre na seção de pacotes e escolha o conjunto desejado. Consulte o valor individual para comprar uma tag específica ou o valor do pacote completo para adquirir todas as tags daquele conjunto.
