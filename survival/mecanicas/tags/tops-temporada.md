# Top Temporada

## Introdução

A categoria Top Temporada conta com 60 tags, que são adquiridas ao ficar no top temporada, os tops ficam no /spawn em alguns npcs.

{% hint style="info" %}
Na página [temporadas-1](../../temporadas-1/ "mention") é possível visualizar as tags e os tops contabilizados.&#x20;
{% endhint %}
