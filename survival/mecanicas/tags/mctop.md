# mcMMO

## Introdução

A categoria mcMMO conta com 28 tags, disponível para uso do jogador que ocupa o primeiro lugar de uma ou mais habilidades do mcMMO, ao atingir o top 1 de uma habilidade, o jogador receberá até duas tags, uma masculina e outra feminina, mas ao sair da topo, perderá as tags imediatamente, ou seja, as tags desta categoria não são permanentes.

{% hint style="info" %}
Para consultar o top de uma habilidade use `/mctop <habilidade>` .
{% endhint %}
