# Elevadores

## Introdução

Os elevadores oferecem uma forma rápida e prática de subir e descer de grandes distancias, o sistema permite que qualquer jogador teleporte de um ponto a outro verticalmente.

## Funcionamento

Para criar um elevador você precisará de no mínimo dois blocos de ametista, ouro, diamante ou netherita e alinhar eles na mesma linha vertical(mantendo o mesmo eixo y).

Cada bloco permite uma distancia entre um ponto e outro distinta

<table><thead><tr><th width="186">Bloco</th><th>Distancia</th></tr></thead><tbody><tr><td>Bloco de Ametista</td><td>Distância máxima de 40 blocos.</td></tr><tr><td>Bloco de Ouro</td><td>Distância máxima de 50 blocos.</td></tr><tr><td>Bloco de Diamante</td><td>Distância máxima de 75 blocos.</td></tr><tr><td>Bloco de Netherita</td><td>Distância máxima de 100 blocos.</td></tr></tbody></table>

### Criação

Ao escolher o bloco da lista para cria o elevador, posicione primeiro bloco, depois no mesmo eixo y coloque o outro bloco do mesmo tipo e respeitando o limite de cada um, após fazer isso, o elevador já estará pronto para uso.&#x20;

### Múltiplos andares

É possível interligar mais de dois pontos para criar um elevador com vários andares, para isso basta alinhar todos os blocos no mesmo eixo y, assim criando os andares, mas lembrando que precisam ser do mesmo tipo.

### Uso

Para usar o elevador, fique em cima do bloco e pule para subir e agache para descer. Caso não funcione, verifique se os blocos estão no mesmo eixo y, se são do mesmo tipo e  se estão respeitando o limite máximo de distancia entre os pontos.&#x20;

{% hint style="warning" %}
## Aviso

Para que o elevador funcione corretamente, toda a coluna deve ser feito com blocos do mesmo material, ou seja, se o elevador foi iniciado com ametista, todos os andares seguintes deverão ser feitos exclusivamente de bloco de ametista.&#x20;
{% endhint %}
