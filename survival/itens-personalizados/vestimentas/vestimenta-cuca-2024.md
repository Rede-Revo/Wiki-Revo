# Set Cuca

## Introdução

O Set Cuca é um conjunto de armadura especial composto por quatro peças de netherite, sendo elas, Capacete, Peitoral, Calça e Botas, ao usar o conjunto completo o jogador receberá um efeito.

## Efeito

Ao equipar o conjunto completo da Cuca o jogador receberá o efeito de Saturação pelo tempo que o conjunto continuar equipado.

{% hint style="info" %}
O efeito só será ativado se o Capacete, Peitoral, Calça e Botas da Cuca estiverem equipados ao mesmo tempo.&#x20;
{% endhint %}

## Encantamentos

## Remoção dos encantamentos

Os encantamentos do Set Cuca podem ser removidos mantendo ainda o efeito Saturação ao estar completamente equipada.
{% endhint %}

## Obtenção

O Set Cuca foi disponibilizado durante a Caixa Tradições Brasileiras de 2024, atualmente o item não pode mais ser obtido oficialmente pelo servidor.

Esse item ainda está circulando pelo servidor, sendo possível obter ele com outros jogadores.&#x20;

{% hint style="info" %}
Por ser um item limitado e serem itens dos jogadores, o valor do item precisa ser negociado diretamente entre os jogadores. O servidor ou a staff não interfere nisso.
{% endhint %}
