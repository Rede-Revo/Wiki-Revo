# Set Tectônico

## Introdução

O Set Tectônico de Páscoa é um conjunto especial de armadura disponibilizado durante a caixa Páscoa 2026.

O conjunto é formado por quatro peças, sendo elas, Capacete Páscoa, Peitoral Páscoa, Calça Páscoa e Botas de Páscoa. Na primeira linha da descrição ou lore é exibido o nível do Tectônico, mas atualmente só existe o nível Tectônico I.

## Efeito

O bônus do conjunto é ativado de acordo com a quantidade de peças com o efeito Tectônico equipadas ao mesmo tempo.

| Peças equipadas | Efeito     |
| --------------- | ---------- |
| 1 Peça          | Sem Efeito |
| 2 Peças         | Pressa I   |
| 3 Peças         | Pressa II  |
| 4 Peças         | Pressa III |

## Descrição

As pelas podem ser identificadas pela sua descrição/lore, os itens que contenham o nível de Tectônico participam dessa contagem para o efeito de pressa.

## Obtenção

O Set Tectônico de páscoa foi disponibilizada durante a Caixa de Páscoa de 2026, atualmente o item não pode mais ser obtido oficialmente pelo servidor.

Esse item ainda está circulando pelo servidor, sendo possível obter ele com outros jogadores.&#x20;

{% hint style="info" %}
Por ser um item limitado e serem itens dos jogadores, o valor do item precisa ser negociado diretamente entre os jogadores. O servidor ou a staff não interfere nisso.
{% endhint %}
