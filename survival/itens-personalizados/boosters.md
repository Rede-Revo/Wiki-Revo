# Boosters

## Introdução

Os Boosters são itens temporários capazes de conceder diferentes benefícios ao jogador, como aumento no ganho de experiência McMMO, bônus de venda, redução no tempo de recarga de habilidades e aumento na chance de ativação das habilidades.

Após a ativação, o benefício permanece ativo durante o período indicado no item.

Você pode consultar seus boosters ativos usando o comando <kbd>/boosts</kbd>.

## Booster de Experiência — McMMO

Os Boosters de Experiência aumentam temporariamente a quantidade de experiência recebida nas habilidades do McMMO.

Existem três versões comuns.&#x20;

Basta beber o item para ativar o benefício.

{% hint style="warning" %}
Não é possível ativer um booster enquanto o outro ainda está ativo. Caso já tenha ativado um booster, precisa aguardar o seu término para ativar o outro.&#x20;
{% endhint %}

{% hint style="info" %}
Jogadores de versões antigas, para ativar, é só ficar segurando o botão de interagir(por padrão botão direito do mouse), não vai aparecer a animação de bebendo, mas é só aguardar segurando que será ativado normalmente em poucos segundos.
{% endhint %}

### Boosters especiais

Em determinadas datas, versões especiais podem ser disponibilizadas com benefícios diferentes dos boosters convencionais.

Esses itens especiais, são capaz de fornecer normalmente 150% a mais de ganho de xp McMMO durante 1 hora.

## Booster de Cooldown — McMMO

O Booster de Cooldown reduz o tempo necessário para que as habilidades do McMMO possam ser utilizadas novamente.

Ele possui uma duração de 7 dias e reduz 33% o tempo de espera para recarga das habilidades.

Enquanto já tiver um Booster de Cooldown ativo, não será possível ativar outro do mesmo tipo.

{% hint style="info" %}
Alguns VIPs já possuem benefícios relacionados ao cooldown de recarga do McMMO como parte das suas vantagens. Nesses casos, a ativação do booster não será permitida, já que o jogador já terá o tipo do booster ativo. \
Consulte a página de [VIPs](https://wiki.rederevo.com/survival/cash/vips#mcmmo)  para mais informações.&#x20;
{% endhint %}

## Booster de Sorte — McMMO

O Booster de Sorte aumenta a chance de ativação das habilidades do mcMMO.

Ele possui uma duração de 7 dias e aumenta 33% a chance de ativações.

Enquanto já tiver um Booster de Sorte ativo, não será possível ativar outro do mesmo tipo.

{% hint style="info" %}
Alguns VIPs já possuem benefícios relacionados a esse como parte das suas vantagens. Nesses casos, a ativação do booster de sorte não será permitida, já que o jogador já terá o tipo do booster ativo. \
Consulte a página de [VIPs](https://wiki.rederevo.com/survival/cash/vips#mcmmo)  para mais informações.&#x20;
{% endhint %}

### Acúmulo com outros benefícios

Você pode usar outros itens para funcionar em conjunto com esse booster.

Por exemplo:\
Booster de Experiência + Talismã de Experiência;\
Booster de Vendas + Varinha de Vendas;\
Booster de Vendas + bônus de um item mágico de Venda e Desconto;\
Booster de Vendas + Varinha de Vendas + item mágico de Venda e Desconto.

{% hint style="warning" %}
Quando diferentes sistemas de bonus são utilizados em conjunto, cada benefício é aplicado conforme sua própria mecânica, por isso, não considere necessariamente as porcentagens como uma simples soma direta.
{% endhint %}

## Como obter

Os boosters convencionais podem ser encontradas na [Caixa Divina](https://wiki.rederevo.com/survival/caixas/divina#itens).

Versões especiais relacionadas a eventos ou datas comemorativas possuem disponibilidade limitada pelo servidor, e por isso, não é mais possível encontrar eles pelo servidor. Após o encerramento, precisa aguardar uma nova data ou negociar com outros jogadores.
