# Talismã de Experiência

## Introdução

O Talismã de Experiência é um item especial que aumenta o ganho de xp do McMMO enquanto estiver sendo utilizado.

{% hint style="info" %}
Para receber seu benefício, mantenha o Talismã equipado na mão secundária.
{% endhint %}

## Níveis

O Talismã possui cinco níveis, quanto maior o nível, maior será o bonus de experiência concedido.&#x20;

## Evolução

É possível juntar Talismãs para tentar aumentar seu nível.

Cada evolução possui uma chance de sucesso, que diminui conforme o nível do item aumenta.

Caso a evolução seja realizada com sucesso, você receberá o Talismã do próximo nível, mas caso a tentativa falhe, os itens utilizados no processos serão destruídos\*.

{% hint style="warning" %}
A evolução não é garantida, confira sempre a chance de sucesso antes de realizar uma tentativa.
{% endhint %}

## Núcleo de Proteção

Para reduzir o risco durante uma evolução, é possível utilizar um Núcleo de Proteção.

Com ele, caso a evolução falhe, um dos itens terá 100% de chance de ser protegido e o outro 50% de chance de ser protegido.

O núcleo é consumido independente do resultado da tentativa, inclusive quando a evolução é realizada com sucesso.

Para mais informações sobre o núcleo, acesse a página do [Núcleo de Proteção](https://wiki.rederevo.com/survival/itens-personalizados/outros/nucleo).

## Uso com Boosters

O bônus fornecido pelo Talismã é independente do sistema de Boosters McMMO, isso significa que você pode usar um Talismã enquanto estiver com o booster McMMO ativo, recebendo assim os dois benefícios ao mesmo tempo.

{% hint style="info" %}
Os talismã de Experiência podem ser encontrados na [Caixa Divina](https://wiki.rederevo.com/survival/caixas/divina#itens).
{% endhint %}





<sup><sub>\*Exceto caso use um Núcleo de Proteção ou sistema equivalente.<sub></sup>
