# Transportador de Mobs

## Introdução

O Transportador de Mobs é um item de uso único que permite capturar um mob e transportar ela para outro lugar, mantendo suas principais informações e características.&#x20;

Ele pode ser usado para transportar mobs entre locais diferentes e até mesmo entre mundos diferentes.

{% hint style="info" %}
O Transportador de Mobs é um item de **uso único**, após ser utilizado para capturar um mob, o item é consumido no processo.
{% endhint %}

## Como usar

Para usar o item é bem simples, basta interagir (botão direito do mouse) com o mob segurando o Transportador de Mobs na mão principal.

Após pegar o mob, a lore irá mudar, mostrando algumas informações sobre o mob capturado.&#x20;

Com o mob capturado dentro do Transportador que você está segurando na mão, para liberar o mob novamente, é só mirar e interagir (clique direito do mouse) onde você quer deixar ele, ou seja, o mob é "colocado" onde está sua mira.

{% hint style="info" %}
O sistema permite teleportar mobs de diferentes mundos.
{% endhint %}

{% hint style="info" %}
Após soltar o mob do transportador, o item será destruído e o mob colocado no novo local.
{% endhint %}

{% hint style="warning" %}
Não é possível usar o Transportador de Mobs em Geradores de criaturas(Spawners).
{% endhint %}

## Dados do mob

Durante o transporte, os dados do mob são mantidos, isso permite mover eles sem perder suas principais informações internas durante o processo de captura e transporte.

{% hint style="danger" %}
### RESTRIÇÃO McMMO

Por mais que os dados internos sejam mantidos, existe uma exceção importante, ao colocar o mob no novo local, o sistema de McMMO para de identificar ele como um mob natural, fazendo com ele não gere xp de McMMO.&#x20;
{% endhint %}

{% hint style="info" %}
O Trasportador de Mobs pode ser encontrado no [Passe de Batalha](https://wiki.rederevo.com/survival/passe-de-batalha).
{% endhint %}
