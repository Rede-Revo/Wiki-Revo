# Editor de Suporte de Armadura

## Introdução

O Editor de Suporte de Armadura é uma ferramenta interativa que permite personalizar os suportes de armadura.

## Como usar

### Funções

Ao pegar o item e interagir com ele sem mirar em um suporte de armadura, abrirá um menu onde será possível configurar várias coisas, como, rotação de cabeça, corpo, braço e pernas, girar em seu próprio eixo, exibir ou ocultar braços e base, modificar o tamanho, posição e brilho, bloquear a capacidade de equipar e retirar itens do suporte de armadura, além de ser possível resetar todas as alterações realizadas.&#x20;

### Uso

1. Segure o Editor de Suporte de Armadura na sua mão principal.
2. Clique com o botão esquerdo ou direito no ar, para abrir o menu da ferramenta.
3. Selecione a opção de edição desejada no menu.
4. Com a ferramenta na mão e após selecionar no menu, clique com o botão esquerdo no suporte de armadura para aplicar a opção escolhida.

{% hint style="info" %}
Clique com o botão direito no suporte para aplicar a edição no sentido inverso (ex: rotacionar para o lado oposto).
{% endhint %}

{% hint style="info" %}
Item com uso exclusivo para jogadores com VIP ativo.
{% endhint %}

### Nomes coloridos

É possível nomear os suportes aplicando etiquetas diretamente neles, sendo possível aplicar todas as cores e efeitos do /cores.

{% hint style="info" %}
Para nomear ou renomear um suporte de armadura não é necessário possuir vip ativo.&#x20;
{% endhint %}
