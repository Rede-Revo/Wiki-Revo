# Transformador de Molduras

## Introdução

O Transformador de molduras é um item utilizado para transformar molduras comuns em molduras invisíveis, permitindo exibir itens sem que a moldura fique visível.

O transformador possui uma quantidade de uso limitada em 32 usos e não pode ser reparado.

## Como usar

Para transformar uma moldura, é necessário possuir um item nela, depois disso, só seguir esse passo a passo:

1. Segure o transformador de moldura na mão principal.
2. Mire e clique na moldura que deseja modificar.
3. A moldura será transformada e ficará invisível.

{% hint style="info" %}
* Apenas molduras com item é possível deixar invisível.
* Cada transformação de moldura, consume 1 uso de durabilidade.
{% endhint %}

## Moldura invisível

Depois de transformada, a estrutura da moldura deixa de ser visível, permanecendo apenas o item colocado nela, isso permite criar decorações diferentes, já que o item visivelmente está colocado diretamente no bloco, sem moldura.

## Remoção do item

O item colocado na moldura pode ser removido normalmente e colocado outro, mas vale ressaltar que a moldura vai continuar lá mesmo vazia, para remover ela, basta quebrar ela normalmente, mas depois disso, ela se tornará uma moldura comum novamente.

{% hint style="warning" %}
Como uma moldura vazia e invisível pode ser difícil localizar visualmente, tenha cuidado ao remover o item dela.
{% endhint %}

## Durabilidade

Cada transformação realizada reduz sua quantidade de usos em 1, ao completar 32 usos, o item será quebrado e não será mais possível utilizar ele.

{% hint style="info" %}
Esse item não pode ser reparado.
{% endhint %}

{% hint style="info" %}
O Transformador de molduras pode ser encontrado na [Caixa Divina](https://wiki.rederevo.com/survival/caixas/divina#itens).
{% endhint %}
