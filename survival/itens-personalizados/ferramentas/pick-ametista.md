# Picareta Ametista

## Introdução

A Picareta Ametista é um ferramenta capaz de coletar Drusas de Amestista, bloco gerador da ametista dentro dos geodos.

Normalmente ao quebrar uma drusa de ametista, o bloco é destruído, sem entregar o drop ao jogador. Utilizando a Picareta Ametista, existe uma chance de conseguir coletar o item.

{% hint style="info" %}
A Picareta Ametista atualmente é a única forma de obter as Drusas de Ametista através de mineração.
{% endhint %}

## Funcionamento

Ao quebrar uma Drusa de Ametista usando a Picareta Ametista, o sistema realiza uma tentativa de drop baseada no nível da ferramenta. Caso a tentativa seja bem sucedida, a Drusa de Ametista será dropada como item, caso contrário, a drusa será destruida e nenhum bloco será dropado.

{% hint style="info" %}
A Drusa de Ametista sempre quebra independente do resultado após a tentativa.
{% endhint %}

### Chance de drop

A chance é definido exclusivamente pelo nível da Picareta, disponível no nome do item.

<table><thead><tr><th width="95.9166259765625">Nível</th><th width="236.1666259765625">Chance de obter a Drusa</th><th width="173">Durabilidade</th></tr></thead><tbody><tr><td>I</td><td>1%</td><td>1.000</td></tr><tr><td>II</td><td>3%</td><td>1.000</td></tr><tr><td>III</td><td>7%</td><td>1.000</td></tr><tr><td>IV</td><td>16%</td><td>1.000</td></tr><tr><td>V</td><td>40%</td><td>1.000</td></tr></tbody></table>

Cada Drusa quebrada é realizada uma nova tentativa individual.

{% hint style="info" %}
A chance indicada na ferramenta é a chance real de drop, encantamentos adicionais como fortuna **não** aumentam a chance de drop das Drusas de Ametista, muito menos aumentam a quantidade de drops realizados, ou seja, no máximo só pode dropar 1 drusa a cada drusa quebrada.
{% endhint %}

{% hint style="info" %}
Ter conseguido coletar a drusa uma vez, não garante que sempre conseguirá, ou seja, a cada quebra, é considerado uma tentativa nova, mesmo que seja uma drusa já coletada e colocada em outro local, a drop passará novamente por uma nova tentativa.
{% endhint %}

{% hint style="warning" %}
Mesmo com a Picareta Ametista, para quebrar a Drusa é necessário desativar o /drusa, caso ativo.
{% endhint %}

## Durabilidade

Todas as versões da Picareta Ametista possuem 1.000 pontos de durabilidade, essa durabilidade é controlada pelo próprio sistema da picareta, e não pela durabilidade padrão do Minecraft.

Cada bloco quebrado consome 1 ponto de durabilidade, isso acontece independente de qual bloco foi quebrado, e independente se teve drop ou não, se o bloco foi quebrado, foi descontado 1 de durabilidade do item.

A durabilidade retorna a 1.000 pontos ao evoluir.

{% hint style="info" %}
Quando a durabilidade do item chegar em 0 pontos, o item será automaticamente quebrado.
{% endhint %}

{% hint style="info" %}
A picareta nível 5 não possui outra evolução, por isso, seus 1.000 usos representam sua durabilidade final.&#x20;
{% endhint %}

## Encantamentos

Encantamentos relacionados a durabilidade do item, não interferem em seu sistema de durabilidade, isso significa que, usar o encantamento Durabilidade ou Remendo nesse item, não fará nenhuma diferença na durabilidade.

Outros encantamentos podem ser colocados no item normalmente.

{% hint style="warning" %}
#### A Picareta Ametista é uma picareta de ouro

Como o item é uma picareta de ouro, não é recomendado utilizar ela como uma ferramenta convencional para mineração, já que picaretas de ouro possuem limitações próprias e não conseguem obter o drop de diversos minérios e blocos. Além disso, qualquer bloco quebrado consumirá obrigatoriamente 1 ponto de durabilidade especial da ferramenta.
{% endhint %}

## Evolução

A Picareta Ametista pode ser evoluída até o nível 5.\
Para realizar uma evolução, é só colocar duas Picaretas Ametistas do mesmo nível através do inventário. Essa evolução tem 100% de chance de acontecer, ou seja, não tem risco de falhar, e sua durabilidade volta a ser de 1.000 pontos.
