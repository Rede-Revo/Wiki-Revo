# Varinha de Vendas

## Introdução

A Varinha de Venda é uma ferramenta especial utilizada para vender itens rapidamente os itens armazenados em armazém, recebendo ainda um bônus especial sobre a venda.&#x20;

Quanto maior o nível da varinha, maior será o bônus concedido.

## Como usar

Segure a Varinha de Vendas e bata no armazém (Botão esquerdo do mouse), contendo os itens que deseja vender, lembrando que são vendidos todos os itens disponíveis para a compra na loja do servidor <kbd>/warp loja</kbd>\*.

A varinha pode ser usada em baús, barris, caixas de Shulker e semelhantes.

Ao usar a varinha, os itens presentes no armazém e caso elegível para venda serão todos vendidos automaticamente, e adicionado o bônus correspondente da varinha.&#x20;

## Evolução

As Varinhas podem ser juntadas para tentar alcançar níveis superiores.

Caso a tentativa falhe, os itens utilizados serão destruídos\*\*.

{% hint style="warning" %}
A evolução não é garantida, confira sempre a chance de sucesso antes de realizar uma tentativa.
{% endhint %}

## Núcleo de Proteção

Para reduzir o risco durante uma evolução, é possível utilizar um Núcleo de Proteção.

Com ele, caso a evolução falhe, um dos itens terá 100% de chance de ser protegido e o outro 50% de chance de ser protegido.

O núcleo é consumido independente do resultado da tentativa, inclusive quando a evolução é realizada com sucesso.

Para mais informações sobre o núcleo, acesse a página do [Núcleo de Proteção](https://wiki.rederevo.com/survival/itens-personalizados/outros/nucleo).

## Uso em conjunto com outros bônus

O bônus da Varinha de Vendas pode funcionar em conjunto com outros benefícios de venda disponíveis, como Booster de Vendas, Bonus de compra e venda, Set de Vendas, Bônus da loja, entre outros.&#x20;

{% hint style="info" %}
Os diferentes benefícios aplicados conforme a mecânica de cada sistema e não devem ser tratados necessariamente como uma simples soma direta das porcentagens.
{% endhint %}

{% hint style="info" %}
Os talismã de Experiência podem ser encontrados na [Caixa Divina](https://wiki.rederevo.com/survival/caixas/divina#itens).
{% endhint %}
